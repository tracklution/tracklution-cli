# Security Policy

## Reporting a vulnerability

If you discover a security vulnerability in this repository, report it
responsibly:

- **Email**: `security@tracklution.com`
- **Subject prefix**: `[security] tracklution-cli`
- Do **not** open a public GitHub Issue for security vulnerabilities.

We will acknowledge receipt within 48 hours and provide a substantive response
within 5 business days. Coordinated-disclosure window is 90 days from
acknowledgement.

## Scope

This repository ships four npm packages that act as a discovery wedge — they
print install instructions to stdout. They do not:

- Handle authentication credentials
- Process user data
- Execute network requests at runtime (the parity test fetches a public
  endpoint; that runs in CI, not user environments)
- Install or run the Tracklution MCP server itself

The Tracklution MCP server at `mcp.tracklution.com` is a separate system. For
MCP-server security concerns, use the same `security@tracklution.com` address
with subject prefix `[security] tracklution-mcp`.

## Supply-chain hygiene

| Property | Status |
|---|---|
| **npm provenance** | All four packages are published with `npm publish --provenance` via [the publish workflow](.github/workflows/publish.yml). The provenance attestation is visible on each package's npmjs.com page. |
| **SLSA level** | Build Level 3 (provenance generated by GitHub Actions in an isolated runner against a public source repo). |
| **Verification (consumer)** | After installing the package, run `npm audit signatures` to verify the attestation chain. Built into npm 9.5+. |
| **Verification (single tarball)** | Pull the provenance attestation bundle from `https://registry.npmjs.org/-/npm/v1/attestations/tracklution@X.Y.Z` (returns a Sigstore bundle JSON), then `npx @sigstore/cli verify <bundle.sigstore.json> --blob-file tracklution-X.Y.Z.tgz`. Or use `cosign verify-blob-attestation --bundle <bundle.json> --new-bundle-format --certificate-oidc-issuer="https://token.actions.githubusercontent.com" tracklution-X.Y.Z.tgz`. |
| **OSSF Scorecard** | Published continuously at `https://api.securityscorecards.dev/projects/github.com/tracklution/tracklution-cli`. |
| **CodeQL** | Daily security scans via [.github/workflows/codeql.yml](.github/workflows/codeql.yml). |

## Bug bounty

We do not run a formal cash bounty, but we do reward verified vulnerability
reports with:

- Credit in this `SECURITY.md` file (a Hall of Fame section, with your
  preferred handle and a link of your choice).
- Tracklution platform credits if your finding is materially impactful
  (proportional to severity, decided case-by-case).
