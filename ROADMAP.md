# Roadmap

The public roadmap lives as a GitHub Project at
[github.com/orgs/tracklution/projects](https://github.com/orgs/tracklution/projects)
under the **tracklution-cli Roadmap** board.

We deliberately do not duplicate roadmap items into this file — the GitHub
Project is the single source of truth, with up-to-date status, assignees, and
linked issues.

## Filing requests

- Bug or compatibility issue with a specific agent → use the
  [Agent Report issue template](.github/ISSUE_TEMPLATE/agent_report.yml).
- New AI coding agent client you want supported → open a
  [Feature Request](.github/ISSUE_TEMPLATE/feature_request.yml). We are
  particularly interested in PRs adding install methods for Aider, Continue,
  Zed, and any other MCP-aware client we don't already cover.
- Big-picture ideas (Python SDK sibling, GitHub Action, embeddable badge, local
  MCP proxy) → start a Discussion in the `Ideas` category.

The next-wave plan covering the embeddable badge, GitHub Action, MCP-directory
submissions, local stdio MCP proxy, Python SDK sibling, and compliance suite is
tracked internally and will be exposed publicly via the Project board when its
items leave the backlog.
